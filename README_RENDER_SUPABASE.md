# Biology Learning

Biology Learning is an AI-assisted educational web application designed to support interactive Biology learning. The project focuses on digital learning content, lesson resources, interactive experience, and a structured learning flow for students.

## Features

- Interactive Biology learning content
- Lesson resources management
- Digital learning experience design
- Supabase database integration
- Backend service deployment on Render
- AI-assisted workflow for planning, content structure, UI ideas, and development support

## Tech Stack

- JavaScript
- React / Frontend framework
- Node.js / Backend
- Supabase
- Render
- HTML/CSS
- AI tools: ChatGPT, Claude/Cursor-assisted workflow

## My Role

I planned and developed this project as an AI Native Web Builder practice project. My work included:

- Analyzing the learning problem and target users
- Designing the content structure and learning flow
- Building the web interface and organizing lesson resources
- Using AI to support planning, content generation, UI improvement, debugging, and optimization
- Deploying the project and connecting it with backend/database services
